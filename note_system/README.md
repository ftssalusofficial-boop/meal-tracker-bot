# SALUS note運用システム

SALUS（東京23区・出張パーソナルトレーニング＋整体）の新規集客用noteアカウントを、下書き自動生成と評価・改善提案の両輪で運用するための仕組み。

## 構成
- `business_profile.json` — 事業・ターゲット・トーンなどの基礎情報
- `content_strategy.md` — コンテンツ方針（ピラー・タイトルの型・CTA・タグ運用）
- `content_calendar.json` — ピラーのローテーション状態・ネタ候補・使用済みトピック
- `past_articles.json` — 運用開始時点の既存8記事の記録
- `analytics_log.csv` — アナリティクス数値の履歴ログ
- `GENERATE_DRAFT.md` — 下書き生成の実行手順（スケジュール実行 or 手動指示で使用）
- `EVALUATE_ACCOUNT.md` — 運用評価・改善提案の実行手順（ブラウザでのログイン確認が必要なため手動トリガー推奨）
- `drafts/` — 生成された下書き（.md）の保存先

## 使い方

### 下書きを生成したいとき
Claude Codeで次のように依頼する：
> `note_system/GENERATE_DRAFT.md` の手順でnote記事の下書きを1本作って

週1〜2本のペースで自動生成するよう、スケジュールタスクとしても登録済み（詳細は下記）。生成された下書きは `drafts/` フォルダに保存されるので、内容を確認してから手動でnoteに投稿する。**自動投稿は行わない。**

### 運用を評価してほしいとき
ブラウザでnoteにログインした状態で、次のように依頼する：
> `note_system/EVALUATE_ACCOUNT.md` の手順で運用を評価して、改善案を出して

アナリティクス画面の数値を一緒に確認しながら、`analytics_log.csv` に記録し、改善提案をまとめる。
