# SALUS note運用方針（コンテンツ戦略）

最終更新: 2026-09-06（v2：自律神経特化を維持する方針に修正） / 参照: [business_profile.json](./business_profile.json), [past_articles.json](./past_articles.json)

## 1. 目的
このnoteアカウントは新規集客のための「名刺代わり・実績提示」。**「自律神経から整える施術者」という尖った差別化ブランディングは維持する。** 一般の方にも読みやすい・興味を持ちやすい入口を用意しつつ、専門性と信頼を積み上げ、最終的に公式HPでの初回体験予約につなげる。

## 2. ファネル
```
検索・興味（肩こり／猫背／頭痛／睡眠 など一般的な悩みキーワード）
   ↓
記事で「実はそれ、自律神経かもしれない」と専門的に橋渡し
   ↓
記事内CTA + プロフィール欄
   ↓
公式HP（https://w-salus.com/）
   ↓
公式LINEで初回体験予約 → 入会
```

## 3. これまでの経緯と方針転換（重要）
v1では「自律神経テーマへの偏重」を課題とし、他ピラーへのローテーションで薄める方針にしていたが、**運営者の意向により方針を修正**：自律神経特化はブランドの核であり変えない。

実際に見えていた問題は「テーマが自律神経であること」自体ではなく、**入口の悩みキーワードと説明の型（フォーマット）の組み合わせが重複していたこと**。特に既存8記事のうち、「睡眠・疲れが取れない」を入口に「症状→原因は自律神経かも」という同じ型で書かれた記事が2本（#5, #8）あり、これが「かぶっている」という感覚の正体。

→ 対策：**入口キーワード × 説明フォーマット** の2軸をどちらもズラすことで、自律神経特化を維持したまま重複を防ぐ。

## 4. 入口キーワード（軸1）
一般の人が検索・共感しやすい悩みワード。**タイトルに必ず1つ含める。**

使用済み：肩こり／頭痛／めまい／動悸／呼吸／睡眠（2回使用・要注意）／だるさ

未使用・優先候補：猫背／姿勢／冷え／むくみ／イライラ・情緒不安定／集中力低下／胃腸の不調／生理不順・PMS／更年期の不調／ダイエットが続かない／運動しても疲れが抜けない

最新の使用状況は [content_calendar.json](./content_calendar.json) の `used_topics` を必ず確認すること。

## 5. 説明フォーマット（軸2）
同じ切り口の反復を避けるため、記事ごとに異なる型を選ぶ。

| 型 | 内容 | 既存での使用例 |
|---|---|---|
| A. タイプ診断系 | 読者を2〜3タイプに分けて自己診断させる | 首肩・顎・骨盤の3タイプ |
| B. 症状原因解説系 | 「その症状、実は自律神経が原因かも」 | 頭痛・めまい／睡眠×2（使いすぎ注意） |
| C. 誤解を正す系 | 「◯◯では治らない理由」など通説を否定して専門性を出す | 肩こりは揉んでも治らない |
| D. メカニズム深掘り系 | 呼吸・神経系など1つの仕組みを掘り下げる | 深呼吸と自律神経 |
| E. 実践ハウツー系 | 理論は最小限、今日からできることが中心 | 朝昼夜の整え方 |
| F. 現場エピソード系 | 8年の臨床経験・実際にあった相談から語る | 8年間で気づいたこと |
| G. トレーニング接続系（未使用・優先） | 自律神経×パーソナルトレーニングを繋げ、差別化を強調 | なし |
| H. Q&A系（未使用） | 実際によく聞かれる質問に答える形式 | なし |
| I. 辞典系（習慣百科スタイル） | 1つの症状に対して複数の具体的な習慣を「テクニック名／やり方／科学的根拠」の3点セットで並べる。書籍『科学的に証明されたすごい習慣大百科』の、見開きで1テクニックが完結する構成を参考にしている | 冷えを根本から見直す習慣4選 |

**ルール**：直近3本は同じフォーマットを使わない。特にB（症状原因解説系）は既に3回使用しているため、しばらく他フォーマットを優先する。G・H・Iは差別化・未開拓のため優先的に使う。

### I（辞典系）を選んだときの書き方
- 記事全体を1つの症状・悩み（入口キーワード）に絞り、その中で3〜5個の具体的な習慣（テクニック）を並べる。5つの違う症状を1記事に詰め込まない（1記事1テーマの原則は守る）。
- 各テクニックは「テクニック名の見出し」→「**やり方**（具体的な手順）」→「**科学的根拠**（なぜ効くのか、根拠を一言で）」の3点セットで書く。
- 科学的根拠は§7のエビデンス方針に従って裏取りするが、**本文中にURLや「（出典：〜）」のような参照は付けない**。地の文で自然に「〜と言われています」「〜と関係が深いことが知られています」のように書く（参照元は自分の作業記録として`sources`に残しておくのみで、読者には見せない）。
- 各テクニックに、SALUS/8年の臨床でしか言えない一言（現場で見えたパターンなど）を添えると、単なる情報の羅列にならない（§5.5の原則はIでも変わらず適用）。

## 5.5 深さ・具体性の担保（重要／2026-09-06追記）
月次バッチで最初に6本生成したところ、運営者から「内容が薄い」という指摘があった。原因は、入口キーワードとフォーマットは変えていても、**書き方の"型"自体（同じヘッジ表現の連呼、症例の欠如）が毎回同じで、どのアカウントでも書けそうな一般論になっていたこと**。以後、次を必須にする。

- **具体的な症例パターンを最低1つ入れる**（F_現場エピソード系だけでなく、原則すべてのフォーマットで）。実在の個人が特定できないよう年齢層・職業・状況は匿名化・複数事例の合成でよいが、「30代・オフィスワークの女性が〜」のように具体的に描写する。架空の症例であることを装って断定的な治療効果を保証しないこと（あくまで「こういう変化が見られた」という経験の共有に留める）。
- **同じヘッジ表現を連呼しない**。「〜と考えられます」「個人差はありますが」を毎段落で使い回さない。経験則の部分は「〜と感じています」「臨床上の実感です」のように、自信を持った言い切りで書いてよい（断定しているのは事実の保証ではなく施術者としての所感であることが文脈で分かるようにする）。
- **どの記事にも通用する一般論で終わらせず、SALUS/8年の臨床でしか言えない具体的な観察を1つ以上入れる**（触診で気づくこと、現場で意外と多いパターン、施術とトレーニングを組み合わせているからこそ見える視点など）。

## 6. 本文構成
1. 導入：読者が抱えていそうな悩み・状況への共感、可能なら具体的な症例から始める（1〜2段落）
2. 本題：自律神経の視点から構造的に解説（選んだフォーマットに沿って構成）
3. 実践できる具体策（今日からできること）
4. まとめ（要点の再整理）
5. **CTAブロック（必須）**：下記テンプレートを毎回文末に入れる

文字数目安：2,500〜4,000字（既存記事と同水準）。トーン：丁寧で専門的、ただし親しみやすさも残す（[business_profile.json](./business_profile.json) の `tone` を参照）。

## 7. エビデンス・ファクトチェック方針（重要）
運営者の意向：「嘘や過剰表現はせず、なるべく裏取り・エビデンスベースにしたい」。2026-09時点で、下書き生成の定期実行タスクにWebSearchツールを接続済み。以下を厳守する。

- 記事の切り口に関連する情報は、**WebSearchで信頼できる情報源（学術機関、医療機関、査読論文、公的機関等）を実際に検索して裏取りする。**
- **本文中・記事末に、URLや「（出典：〜）」といった参照は付けない**（2026-09-08変更：以前は記事末に「参考情報」としてURLを列挙していたが、note記事としては不自然という運営者の意向により廃止）。裏取りした内容は、地の文で「〜と言われています」「〜と関係が深いことが知られています」のように自然に書く。検索で確認した出典は、下書きのフロントマター `sources` にだけ記録し、読者には見せない（万が一の確認用の作業記録）。
- **具体的な研究名・著者名・雑誌名・統計数値（「◯%の人が」等）を、検索で実在の確認が取れないまま創作しない。** 検索しても裏付けが取れない情報は書かない。
- 生理学的に広く確立されているメカニズム（交感神経・副交感神経の基本的な働き、呼吸と自律神経の関係、慢性的な筋緊張とストレス反応の関係など）は、一般的な生理学の知識として書いてよい（検索で個別に裏取りできなくても可）。
- 検索しても裏付けが取れなかった、または情報源の信頼性が低いと判断した場合は、断定を避けた一般的な書き方に留め、記事のメタ情報に `needs_fact_check: true` を付け、本文中の当該箇所を `[要出典確認]` とマークする。**投稿前に運営者が確認・裏取りするまでは投稿しない。**
- 効果を保証する表現（「必ず治る」「100%改善する」等）や、医療広告・薬機法・景表法に抵触しうる断定表現は禁止。「個人差があります」等の前提を自然に含める。
- 施術者自身の臨床経験（8年間の現場感覚）に基づく記述は、研究引用ではなく「経験則」として書き、混同させない。

## 9. タグ運用
- 固定推奨タグ（発見用）：`#自律神経` `#整体` `#肩こり` `#睡眠` `#パーソナルトレーニング`

## 9.5 図解ポリシー（2026-09-06追記）
記事1本につき1〜2枚、説明用の図解を入れる。

- **実在の人物・施術風景を装う画像（AI生成の人物写真など）は作らない。** 実際の写真を使いたい場合は運営者が自分で撮影・提供したものを使う。図解はあくまで「自律神経の仕組み」「タイプ比較」などを視覚的に整理する目的に限定する。
- 図解は `note_system/scripts/diagram_helpers.py` を使ってPythonで生成する（`two_panel_compare` / `three_panel_compare` / `bidirectional_pair` / `timeline` など）。フォントは `note_system/assets/fonts/` に同梱したM PLUS 1pを使うため、クラウド実行環境でも同じ見た目で生成できる。
- 生成手順：`pip install matplotlib` → 生成スクリプトを実行 → `note_system/drafts/images/` にPNGとして保存 → 記事の該当箇所に `![説明](./images/ファイル名.png)` の形で挿入する。
- どこに挿入するかの目安：本題の中心となる比較・仕組みの直後（1枚目）、実践パートの直前（2枚目、入れる場合）。
- note.comはMarkdownの画像記法をそのまま読み込まないため、投稿時は該当箇所にnoteのエディタから画像を手動アップロードする（下書きのメタ情報や本文に一言メモを残す必要はないが、ファイル名から画像が分かるようにしておく）。

## 10. やらないこと
- 断定的な医療効果の保証（「必ず治る」等）は書かない。個人差がある旨を自然に含める。
- 実在確認できない研究・統計を創作しない（§7参照）。
- 過度な煽り・薬機法/景表法に抵触しうる表現は避ける。
- 直近3本と同じ「入口キーワード×フォーマット」の組み合わせを使わない。
- 一記事に情報を詰め込みすぎない（1記事1テーマ）。
