# SALUS note運用方針（コンテンツ戦略）

最終更新: 2026-09-06 / 参照: [business_profile.json](./business_profile.json), [past_articles.json](./past_articles.json)

## 1. 目的
このnoteアカウントは新規集客のための「名刺代わり・実績提示」。売り込み色を出しすぎず、専門性と信頼を積み上げながら、最終的に公式HPでの初回体験予約につなげる。

## 2. ファネル
```
検索・興味（整体／体の悩み系キーワード）
   ↓
note記事で専門性と共感を提供
   ↓
記事内CTA + プロフィール欄
   ↓
公式HP（https://w-salus.com/）
   ↓
公式LINEで初回体験予約 → 入会
```

## 3. 現状の課題（2026-09-06時点の評価より）
1. **CTAが存在しない** — 全8記事、本文末に公式HP・LINEへの導線が無い。プロフィール欄任せになっており、ファネルが機能していない。
2. **テーマの偏り** — 8記事全てが「自律神経」系。パーソナルトレーニングの強み・大会実績・姿勢改善の具体的施術など、差別化要素が語られていない。
3. **入口キーワードの弱さ** — 「整体」を入口にする方針に対し、タイトルは「自律神経」中心。「肩こり」「猫背」「整体 東京」のような検索意図の強いワードがタイトルに少ない。
4. **フォロワー0人** — 2ヶ月弱・8記事運用してフォロワー増加ゼロ。発見導線（タグ・タイトル・他SNS連携）の見直しが必要。

[content_calendar.json](./content_calendar.json) の `pillar_rotation` 順に生成する。直近が自律神経に偏っていたため、次は「整体・体の悩み系」から再開する。

## 5. タイトルの型
`[悩み・検索ワード] + [専門的な視点/意外性] + （必要に応じて）[整体師/柔道整復師が解説 等の権威づけ]`

例:
- 「肩こりが取れない本当の原因｜マッサージでは届かない層へのアプローチ」
- 「猫背は整体で本当に治るのか｜姿勢矯正の限界と現実的な向き合い方」

悩みワード（肩こり／猫背／腰痛／頭痛／自律神経／姿勢／疲労）のいずれかを**必ずタイトルに含める**。

## 6. 本文構成（既存記事のトーンを踏襲）
1. 導入：読者が抱えていそうな悩み・状況への共感（1〜2段落）
2. 本題：専門的な視点で構造的に解説（見出し2〜4個、タイプ分け・ステップ分けなど整理された形式）
3. 実践できる具体策（今日からできること）
4. まとめ（要点の再整理）
5. **CTAブロック（新規追加・必須）**：下記テンプレートを毎回文末に入れる

文字数目安：2,500〜4,000字（既存記事と同水準）。丁寧語・専門的だが親しみやすいトーン（[business_profile.json](./business_profile.json) の `tone` を参照）。

## 7. CTAテンプレート（本文末に毎回挿入）
```
─────────────

ここまで読んでくださった方へ

東京23区に出張する、パーソナルトレーニング×整体のSALUS（セラス）。
姿勢・体の使い方から整えたい方は、公式HPから初回体験のご予約が可能です（現在、体験料・入会金無料キャンペーン中）。

→ 公式HP：https://w-salus.com/
```
※記事のテーマに応じて1文目だけ内容に合わせて調整してよい。売り込みが強くなりすぎないよう「ここまで読んでくださった方へ」のトーンは維持する。

## 8. タグ運用
毎回、発見用の広いタグ + 記事固有タグを組み合わせる。
- 固定推奨タグ（発見用）：`#整体` `#肩こり` `#自律神経` `#姿勢改善` `#パーソナルトレーニング`
- 記事固有タグ：テーマに応じて1〜2個追加（例：`#筋膜リリース` `#猫背` `#睡眠`）

## 9. やらないこと
- 断定的な医療効果の保証（「必ず治る」等）は書かない。個人差がある旨を自然に含める。
- 過度な煽り・薬機法/景表法に抵触しうる表現は避ける。
- 一記事に情報を詰め込みすぎない（1記事1テーマ）。
