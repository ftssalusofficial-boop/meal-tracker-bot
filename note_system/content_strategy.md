# SALUS note運用方針（コンテンツ戦略）

最終更新: 2026-09-06（v2：自律神経特化を維持する方針に修正） / 参照: [business_profile.json](./business_profile.json), [past_articles.json](./past_articles.json)

## 1. 目的
このnoteアカウントは新規集客のための「名刺代わり・実績提示」。**「自律神経から整える施術者」という尖った差別化ブランディングは維持する。** 一般の方にも読みやすい・興味を持ちやすい入口を用意しつつ、専門性と信頼を積み上げ、最終的に公式HPでの初回体験予約につなげる。

## 2. ファネル
```
検索・興味（肩こり／猫背／頭痛／睡眠 など一般的な悩みキーワード）
   ↓
記事で「実はそれ、自律神経かもしれない」と専門的に橋渡し
   ↓
記事内CTA + プロフィール欄
   ↓
公式HP（https://w-salus.com/）
   ↓
公式LINEで初回体験予約 → 入会
```

## 3. これまでの経緯と方針転換（重要）
v1では「自律神経テーマへの偏重」を課題とし、他ピラーへのローテーションで薄める方針にしていたが、**運営者の意向により方針を修正**：自律神経特化はブランドの核であり変えない。

実際に見えていた問題は「テーマが自律神経であること」自体ではなく、**入口の悩みキーワードと説明の型（フォーマット）の組み合わせが重複していたこと**。特に既存8記事のうち、「睡眠・疲れが取れない」を入口に「症状→原因は自律神経かも」という同じ型で書かれた記事が2本（#5, #8）あり、これが「かぶっている」という感覚の正体。

→ 対策：**入口キーワード × 説明フォーマット** の2軸をどちらもズラすことで、自律神経特化を維持したまま重複を防ぐ。

## 4. 入口キーワード（軸1）
一般の人が検索・共感しやすい悩みワード。**タイトルに必ず1つ含める。**

使用済み：肩こり／頭痛／めまい／動悸／呼吸／睡眠（2回使用・要注意）／だるさ

未使用・優先候補：猫背／姿勢／冷え／むくみ／イライラ・情緒不安定／集中力低下／胃腸の不調／生理不順・PMS／更年期の不調／ダイエットが続かない／運動しても疲れが抜けない

最新の使用状況は [content_calendar.json](./content_calendar.json) の `used_topics` を必ず確認すること。

## 5. 説明フォーマット（軸2）
同じ切り口の反復を避けるため、記事ごとに異なる型を選ぶ。

| 型 | 内容 | 既存での使用例 |
|---|---|---|
| A. タイプ診断系 | 読者を2〜3タイプに分けて自己診断させる | 首肩・顎・骨盤の3タイプ |
| B. 症状原因解説系 | 「その症状、実は自律神経が原因かも」 | 頭痛・めまい／睡眠×2（使いすぎ注意） |
| C. 誤解を正す系 | 「◯◯では治らない理由」など通説を否定して専門性を出す | 肩こりは揉んでも治らない |
| D. メカニズム深掘り系 | 呼吸・神経系など1つの仕組みを掘り下げる | 深呼吸と自律神経 |
| E. 実践ハウツー系 | 理論は最小限、今日からできることが中心 | 朝昼夜の整え方 |
| F. 現場エピソード系 | 8年の臨床経験・実際にあった相談から語る | 8年間で気づいたこと |
| G. トレーニング接続系（未使用・優先） | 自律神経×パーソナルトレーニングを繋げ、差別化を強調 | なし |
| H. Q&A系（未使用） | 実際によく聞かれる質問に答える形式 | なし |

**ルール**：直近3本は同じフォーマットを使わない。特にB（症状原因解説系）は既に3回使用しているため、しばらく他フォーマットを優先する。GとHは差別化・未開拓のため優先的に使う。

## 6. 本文構成
1. 導入：読者が抱えていそうな悩み・状況への共感（1〜2段落）
2. 本題：自律神経の視点から構造的に解説（選んだフォーマットに沿って構成）
3. 実践できる具体策（今日からできること）
4. まとめ（要点の再整理）
5. **CTAブロック（必須）**：下記テンプレートを毎回文末に入れる

文字数目安：2,500〜4,000字（既存記事と同水準）。トーン：丁寧で専門的、ただし親しみやすさも残す（[business_profile.json](./business_profile.json) の `tone` を参照）。

## 7. エビデンス・ファクトチェック方針（重要）
運営者の意向：「嘘や過剰表現はせず、なるべく裏取り・エビデンスベースにしたい」。2026-09時点で、下書き生成の定期実行タスクにWebSearchツールを接続済み。以下を厳守する。

- 記事の切り口に関連する情報は、**WebSearchで信頼できる情報源（学術機関、医療機関、査読論文、公的機関等）を実際に検索して裏取りする。** 検索結果から実在するものだけを引用し、可能な限り出典（URL・機関名）を記事末の「参考情報」に明記する。
- **具体的な研究名・著者名・雑誌名・統計数値（「◯%の人が」等）を、検索で実在の確認が取れないまま創作しない。** 検索しても裏付けが取れない情報は書かない。
- 生理学的に広く確立されているメカニズム（交感神経・副交感神経の基本的な働き、呼吸と自律神経の関係、慢性的な筋緊張とストレス反応の関係など）は、一般的な生理学の知識として書いてよい（検索で個別に裏取りできなくても可）。
- 検索しても裏付けが取れなかった、または情報源の信頼性が低いと判断した場合は、断定を避けた一般的な書き方に留め、記事のメタ情報に `needs_fact_check: true` を付け、本文中の当該箇所を `[要出典確認]` とマークする。**投稿前に運営者が確認・裏取りするまでは投稿しない。**
- 効果を保証する表現（「必ず治る」「100%改善する」等）や、医療広告・薬機法・景表法に抵触しうる断定表現は禁止。「個人差があります」等の前提を自然に含める。
- 施術者自身の臨床経験（8年間の現場感覚）に基づく記述は、研究引用ではなく「経験則」として書き、混同させない。

## 8. CTAテンプレート（本文末に毎回挿入）
```
─────────────

ここまで読んでくださった方へ

東京23区に出張する、パーソナルトレーニング×整体のSALUS（セラス）。
自律神経の視点から体を整えたい方は、公式HPから初回体験のご予約が可能です（現在、体験料・入会金無料キャンペーン中）。

→ 公式HP：https://w-salus.com/
```
※記事のテーマに応じて1文目だけ内容に合わせて調整してよい。売り込みが強くなりすぎないよう「ここまで読んでくださった方へ」のトーンは維持する。

## 9. タグ運用
- 固定推奨タグ（発見用）：`#自律神経` `#整体` `#肩こり` `#睡眠` `#パーソナルトレーニング`
- 記事固有タグ：入口キーワードに応じて1〜2個追加（例：`#猫背` `#冷え性` `#呼吸`）

## 10. やらないこと
- 断定的な医療効果の保証（「必ず治る」等）は書かない。個人差がある旨を自然に含める。
- 実在確認できない研究・統計を創作しない（§7参照）。
- 過度な煽り・薬機法/景表法に抵触しうる表現は避ける。
- 直近3本と同じ「入口キーワード×フォーマット」の組み合わせを使わない。
- 一記事に情報を詰め込みすぎない（1記事1テーマ）。
